Claude Code, on this phone.

Pocket Agent runs Claude Code in its own small Linux system inside the app. No Termux, no computer needed.

~300 MBto download, once
~600 MBof storage used
3–8 minon Wi-Fi
…free on this phone

Setting things up

Keep Pocket Agent open until this finishes (Android may stop it in the background), and stay on Wi-Fi if you can. If it gets interrupted, it picks up where it left off.
